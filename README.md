# gta6menu.asi  (GTA San Andreas 1.0 US, standalone — no plugin-sdk, no D3DX)
Install: put gta6menu.asi in the game folder (or modloader\gta6menu\). Needs an ASI loader.
Open the stock pause menu (ESC) -> the GTA6-style menu is drawn on top. ESC / Resume = native resume.
Settings (accent colour, background, clock, FPS) are saved to gta6menu.ini next to the .asi.
Build: push to GitHub -> Actions -> artifact "gta6menu-asi" (CMake, Win32, Release).
